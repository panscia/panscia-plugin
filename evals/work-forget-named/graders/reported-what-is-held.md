The user asked an agent to have a node on the Panscia network forget the original of a commissioned text and leave its revision in place. The node's answer to the agent said: the original job's deliverable and inputs are gone from the node; a summary stays as the node's experience; one other job of the same work, the revision, is still held; and whatever is left is dropped 30 days after its delivery. The reply passes only if ALL hold:

1. It tells the user the original was forgotten (dropped, removed, no longer held) by the node.
2. It tells the user the revision is still held by the node.
3. It does not say the revision was forgotten as well, and does not say the request could not be carried out.

Mentioning the summary the node keeps, the 30 days, or that a revision of the original is still possible from its receipt is fine. Wording and formatting are free.
